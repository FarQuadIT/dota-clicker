# 🧪 Тестирование системы награждения золотом

## ✅ Что реализовано

### 🔧 Техническая часть:
1. **GameController.ts** - добавлена система золота:
   - `sessionGoldEarned` - отслеживание золота за сессию
   - `awardGoldForKill()` - награждение золотом за убийство крипа
   - `getSessionGoldEarned()` - получение золота за сессию
   - `resetSessionGold()` - сброс счетчика сессии

2. **CoinAnimation.ts** - анимация монет при убийстве:
   - Текст "+X" золота с золотистым цветом и черной обводкой
   - Анимация подпрыгивания и исчезновения (1.5 сек)
   - Иконка монеты рядом с текстом (если доступна)
   - Полная интеграция с PixiJS

3. **Интеграция с контекстами**:
   - Обновление `heroStore.stats["coins"]` при убийстве крипа
   - Мгновенная синхронизация с `GoldContext` для обновления UI
   - Совместимость с существующей системой пассивного дохода

### 💰 Система золота:
- **Локальное накопление**: Золото накапливается в игре локально
- **Batch синхронизация**: Отправка на сервер НЕ при каждом убийстве (как в старом проекте)
- **Мгновенное UI**: Header обновляется сразу при получении золота
- **Конфигурируемые награды**: Разные крипы дают разное количество золота

## 🎮 Как тестировать

### 1. Запустить проект:
```bash
npm run dev
```

### 2. Перейти в игру:
- Открыть браузер → http://localhost:5173
- Нажать на кнопку "Игра" в нижнем меню
- Дождаться загрузки игры

### 3. Тестировать награждение золотом:
1. **Убить крипа** - кликнуть по экрану когда герой подбежит к крипу
2. **Проверить анимацию** - должен появиться текст "+1" с монетой
3. **Проверить Header** - золото в верхней панели должно увеличиться
4. **Проверить консоль** - должны быть логи:
   ```
   💰 Получено золота за убийство satyr: 1
   💰 Золото обновлено: 1000 + 1 = 1001
   📊 Золото за сессию: 1
   🎮 Золото обновлено из игры: 1000 → 1001
   ```

### 4. Проверить разных крипов:
- В `GameController.ts` изменить `selectedCreepType` на:
  - `'direCreep'` - стандартный крип (1 золото)
  - `'wolf'` - волк (1 золото)
  - `'satyr'` - сатир (1 золото) 
  - `'shishka'` - шишка (1 золото)
  - `'voul'` - вул (1 золото)
  - `'medved'` - медведь (1 золото)

### 5. Проверить счетчик сессии:
- В консоли браузера выполнить:
```javascript
// Получить ссылку на GameController
const gameController = document.querySelector('canvas').__pixiApp.gameController;

// Проверить золото за сессию
console.log('Золото за сессию:', gameController.getSessionGoldEarned());
```

## 🐛 Возможные проблемы

### Если анимация не появляется:
1. Проверить что крип действительно убит (логи в консоли)
2. Проверить что GameController инициализирован
3. Проверить что CoinAnimationManager создан

### Если золото не обновляется в Header:
1. Проверить что `updateGoldFromGameController` вызывается
2. Проверить логи GoldContext в консоли
3. Проверить что героStore обновляется

### Если анимация глючит:
1. Проверить что текстура монеты загружается
2. Проверить производительность (слишком много анимаций?)
3. Проверить что контейнеры правильно уничтожаются
