# Тестирование системы прогрева текстур крипов

## Что реализовано

Система прогрева текстур крипов, которая:

1. **Предварительно создает** всех крипов для текущего уровня в нормальном размере и видимыми
2. **Размещает их за экраном** справа (в 2 раза дальше правого края)
3. **Сохраняет оригинальную позицию по Y** для каждого типа крипа
4. **Переиспользует готовых крипов** - просто перемещает их в игровую зону при спавне

## Как тестировать

### 1. Запуск игры
```bash
npm run dev
```

### 2. Проверка консоли
При запуске игры в консоли браузера должны появиться сообщения:
```
🔥 Предварительный прогрев текстур для уровня 1...
🔥 Прогрев текстур для уровня 1...
✅ Прогрев завершен! Готово 10 крипов для уровня 1
✅ Предварительный прогрев уровня 1 завершен
```

### 3. Проверка спавна крипов
При появлении каждого нового крипа должны появляться сообщения:
```
✅ Используем прогретого крипа из очереди
```

Если появляется:
```
⚠️ Создаем крипа обычным способом (прогрев не сработал)
```
То система прогрева не работает корректно.

### 4. Тест производительности

**До реализации прогрева:**
- Первый спавн крипа каждого типа вызывал лаг
- Особенно заметно на слабых устройствах

**После реализации прогрева:**
- Спавн крипов должен происходить плавно
- Лаг должен происходить только один раз в начале уровня
- Все последующие спавны без лагов

### 5. Визуальная проверка

1. Если прокрутить камеру вправо (если возможно), должны быть видны готовые крипы за экраном
2. Крипы за экраном должны быть в нормальном размере и видимыми
3. При спавне крип должен плавно "выезжать" из-за экрана
4. Позиция по Y должна сохраняться (не изменяться при перемещении из-за экрана)

### 6. Проверка памяти

В DevTools -> Performance:
1. Запустить запись
2. Поиграть 1-2 минуты
3. Проверить, что нет аномальных скачков памяти
4. Система должна переиспользовать крипов, а не создавать новых

## Настройки системы

В файле `src/game/managers/TextureWarmupManager.ts` можно изменить:

```typescript
const config = {
  offscreenPositionX: 2.0,    // Позиция крипов за экраном (2.0 = в 2 раза дальше правого края)
  creepsPerLevel: 10,         // Количество крипов для прогрева на уровень
}
```

## Отключение системы

Для отключения системы прогрева (например, для сравнения):
```typescript
// В GameController.ts в конструкторе
this.textureWarmupManager = new TextureWarmupManager(this.app, {
  // Отключаем систему прогрева
});
this.textureWarmupManager.setWarmupActive(false);
```

## Ожидаемые результаты

### ✅ Успешная работа:
- Консоль показывает успешный прогрев
- Крипы спавнятся плавно
- Лаг только в начале уровня
- FPS стабильный

### ❌ Проблемы:
- Ошибки в консоли при прогреве
- Крипы создаются "fallback" способом
- Лаги при каждом спавне
- Падение FPS

## Дополнительные тесты

1. **Смена уровня**: Проверить, что при переходе на новый уровень система прогревает новые типы крипов
2. **Ресайз окна**: Проверить, что система корректно обрабатывает изменение размера окна
3. **Пауза/возобновление**: Проверить, что система корректно работает при паузе игры
4. **Перезапуск игры**: Проверить, что система корректно очищается и переинициализируется

## Отладка

Если система не работает, проверить:
1. Загружены ли все текстуры в AssetsManager
2. Правильно ли определяются типы крипов для уровня
3. Нет ли ошибок в методе `createWarmupCreep`
4. Корректно ли работает метод `resetToInitialState` в классе Creep

## Метрики

- Время прогрева уровня
- Количество созданных крипов
- Использование готовых vs создание новых
- Ошибки при прогреве
